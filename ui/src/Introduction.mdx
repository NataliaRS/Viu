## Qué es

VIU es la **fuente única de verdad** del producto: tokens (primitivos → semánticos → temas)
y una biblioteca de componentes que los consumen. Lo que ves acá se genera desde las mismas
variables que viven en Figma, así que **diseño y código no se desincronizan**.

- **Foundations** — colores, tipografía, espaciado, radios, efectos y grid, leídos de los tokens.
- **Components** — átomos (y, próximamente, moléculas, organismos y patrones), cada uno con sus
  variantes, estados y mapeo a Figma vía Code Connect.

## Instalación y uso

```bash
npm install @viu/design-tokens @viu/ui
```

```tsx
// 1) Tokens (CSS variables + temas) — una vez, a nivel app
import "@viu/design-tokens/css";
// 2) Estilos de los componentes
import "@viu/ui/styles";

import { Button, Icon } from "@viu/ui";

export function Example() {
  return (
    <Button variant="primary" leadingIcon={<Icon glyph="Plus" />}>
      Crear
    </Button>
  );
}
```

## Theming

El tema por defecto es **dark** (black-first). Para tema claro, seteá `data-theme` en la raíz:

```html
<html data-theme="light"> … </html>
```

Sin `data-theme`, el sistema sigue el modo del sistema operativo (`prefers-color-scheme`).
En este Storybook podés cambiar el tema con el control **Tema** en la barra superior ↑.

## Reglas del sistema

- Los componentes consumen **solo** tokens semánticos / escalas / tipografía / motion — nunca
  hex ni valores sueltos.
- El color semántico (`--color-bg|text|border|feedback-*`) es la única capa de color que se usa
  en componentes.
- Tipografía responsive: Mobile por defecto, Desktop ≥ 1024px.
