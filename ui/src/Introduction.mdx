## Qué es

VIU es la **fuente única de verdad** del producto: tokens (primitivos → semánticos → temas)
y una biblioteca de componentes que los consumen. Lo que ves acá se genera desde las mismas
variables que viven en Figma, así que **diseño y código no se desincronizan**. No es un catálogo de
piezas sueltas: es un criterio compartido para construir con la misma voz.

- **Foundations** — colores, tipografía, espaciado, radios, efectos y grid, leídos de los tokens.
- **Components** — un sistema de átomos, moléculas, organismos y patrones, cada uno con sus
  variantes, estados, accesibilidad verificada y mapeo a Figma vía Code Connect.

## Principios que lo gobiernan

Cinco reglas, en voz propia, detrás de cada decisión del sistema.

- **El sistema desaparece.** La mejor interfaz no se nota: lógica clara y cero fricción. Si una pieza
  llama la atención sobre sí misma, sobra.
- **Autoridad, no novedad.** Calidad editorial y contención antes que adorno o tendencia; nada lee
  como tentativo.
- **Cada elemento comunica — o se quita.** Retícula, jerarquía y un solo acento por superficie.
- **Accesible y humana, sin excepción.** WCAG 2.2 AA verificado con números (4.5:1 texto, 3:1
  grande/UI), foco siempre visible, estado por color + información. Es piso, no un extra.
- **Específica, nunca genérica.** Si una decisión podría aparecer igual en cualquier otro sistema, se
  replantea.

## Instalación y uso

```bash
npm install @viu/design-tokens @viu/ui
```

```tsx
// 1) Tokens (CSS variables + temas) — una vez, a nivel app
import "@viu/design-tokens/css";
// 2) Estilos de los componentes
import "@viu/ui/styles";

import { Button, Icon } from "@viu/ui";

export function Example() {
  return (
    <Button variant="primary" leadingIcon={<Icon glyph="Plus" />}>
      Crear
    </Button>
  );
}
```

## Theming

El tema por defecto es **dark** (black-first). Para tema claro, seteá `data-theme` en la raíz:

```html
<html data-theme="light"> … </html>
```

Sin `data-theme`, el sistema sigue el modo del sistema operativo (`prefers-color-scheme`).
En este Storybook podés cambiar el tema con el control **Tema** en la barra superior ↑.

## Reglas del sistema

- Los componentes consumen **solo** tokens semánticos / escalas / tipografía / motion — nunca
  hex ni valores sueltos.
- El color semántico (`--color-bg|text|border|feedback-*`) es la única capa de color que se usa
  en componentes.
- Tipografía responsive: Mobile por defecto, Desktop ≥ 1024px.
